# HAVIT SNS 발행 전략 (2026-10-24 대표 결정 반영)

## 1. 물량 — 언어마다 하루 5건, 9개 언어 = 하루 45건

| 계정 | 하루 | 현지 시각 | 형태 |
|---|---|---|---|
| Instagram | 2 | 12:00 · 19:00 | 캐러셀(카드 6~10장) |
| Threads | 2 | 08:00 · 20:00 | 카드 이미지 1장 + 짧은 글 |
| Threads | 1 | 12:00 | 블로그 링크 미리보기 글(카드 없음, 글 제목·대표 이미지가 붙음) |

- 같은 계정이 같은 날 같은 글·같은 포맷을 쓰지 않는다(`plan.mjs`가 보장).
- 같은 계정에서는 14일 안에 같은 사진을 다시 쓰지 않는다(`imagery.mjs`).

## 2. 포맷 — 저장·공유·답글이 일어나는 형태로

알고리즘은 **저장·공유(Instagram)**와 **답글(Threads)**에 가장 크게 반응한다. 포맷은 그 행동을 직접 유도하도록 짰다.

| 채널 | 포맷 | 노리는 반응 |
|---|---|---|
| Instagram | `quiz_carousel` 맞혀 보기 → 정답 공개 | 끝까지 넘김(체류) + 공유 |
| | `versus_carousel` A vs B | 저장·공유 |
| | `recipe_carousel` 건강 레시피(글에 나온 음식만) | 저장 |
| | `mistakes_carousel` 흔한 실수 N가지 | 저장 |
| | `myth_fact` · `checklist` · `steps` · `one_stat` · `havi_scene` | 저장 |
| Threads | `hot_take` 통념 뒤집기 | 답글(동의·반박) |
| | `ab_question` A냐 B냐(정답은 글이나 첫 답글에) | 답글 |
| | `recipe_quick` 한 줄 레시피 | 저장·공유 |
| | `question` · `one_stat` · `myth_fact` · `mini_steps` · `havi_scene` | 답글 |
| | `link_teaser` 블로그 유입용 | 클릭(블로그 → 앱) |

- 레시피는 `sources.json`에 `recipe_ok` 표시가 있는 음식 글에만 배정한다. 지금은 7편, 주 5건 정도다. 음식 글이 늘면 레시피 비중도 따라 늘어난다.
- 레시피에는 글에 없는 칼로리·그램을 쓰지 않는다(사실 규칙). 재료도 글에 나온 음식만 쓴다.

## 3. 후킹 — 첫 1.5초

- 쓰기 전에 서로 다른 패턴으로 후킹 문장 3개를 만들고 가장 강한 것을 고른다. 나머지 2개는 `hook_alternatives`에 남긴다(나중에 A/B 시험 재료).
- 패턴: 통념 뒤집기 · 구체적 수치 · 일상 장면 · 그만할 것 · 답을 주는 궁금증.
- 이기는 후킹: 구체적(숫자·시각·음식·몸 신호), 긴장이나 반전, 12단어 이하.
- 금지: "알고 계셨나요", "N가지 팁", 낚시(본문이 답하지 않는 궁금증), 공포 조장, 느낌표 남발.
- 리뷰어(Opus)가 후킹을 1~5점으로 채점한다. 4점 미만이면 더 센 후킹 예시를 붙여 돌려보내고, 생성기가 1회 고쳐 쓴다(`revise.mjs`). 두 번째도 미달이면 그날은 발행하지 않는다(사람 승인 부담 없음).

## 4. 본문 카피

1. 1줄 = 후킹, 2줄 = 즉시 답(발견·답·반전). 기다리게 하지 않는다.
2. 그다음 쓸모: 오늘 바로 할 수 있는 구체적인 것. 짧은 줄, 한 줄에 한 생각.
3. 마지막 행동은 하나만: 저장(체크리스트·레시피·단계) / 보내기(공감 장면) / 답하기(Threads 질문). "좋아요+댓글+공유" 같은 나열은 금지.
4. Instagram은 '더 보기' 전 125자 안에 후킹과 답이 둘 다 들어가야 한다.
5. 브랜드 계정이 지어낸 1인칭 경험담은 금지("제가 해 봤더니"). 2·3인칭 장면으로 쓴다.

## 5. 검색 최적화(해시태그·키워드)

Instagram과 Threads는 캡션·대체 텍스트·해시태그를 검색에 쓴다.

- **대표 검색 키워드 1개**: 그 언어 사용자가 실제로 검색창에 칠 말(예: ko "단백질 식단", ja "睡眠の質", en "protein breakfast"). 글 제목의 전문용어가 아니라 일상어로 고른다.
  - 위치: 캡션 첫 문장 · 표지 제목 또는 alt_text · `keywords` 필드
  - 기계 검사: 키워드가 없으면 FAIL, 첫 125자 밖이면 경고
- **Instagram 해시태그 3~5개** = 브랜드 태그 1(ko `#하비트`, ja·zh-tw `#HAVIT`, 그 외 `#HAVITapp`) + 그 언어에서 실제로 팔로우되는 니치 태그 2~3 + 넓은 태그 최대 1.
  - 금지: `#love` `#instagood` 같은 초대형 태그, 매번 같은 세트 반복.
  - 기계 검사: 브랜드 태그가 없으면 경고.
- **Threads**: 토픽 태그 최대 1개(대표 키워드를 태그로). 브랜드 태그는 붙이지 않는다.
- **alt_text**: 표지 이미지를 설명하고 대표 키워드를 1회 넣는다.
